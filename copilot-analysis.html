🔑 Feature Flags Decoded

The token contains numerous capability flags:

  • agent_mode_auto_approval=1 - Auto-approve certain agent actions

Two-Token System

Copilot uses two distinct token types:

  1. GitHub PAT (Personal Access Token): Starting with gho_, used for account-level API calls like agent sessions and configuration checks
  2. Bearer Token: Short-lived JWT with feature flags, used for LLM inference calls

Health check endpoint. Returns "OK" with minimal latency (~450ms).

Main chat completion endpoint using Anthropic's message API format. Supports streaming with SSE. Average response time: 60-95 seconds for complex requests.

OpenAI-compatible chat completions endpoint. Used for internal summarization and lightweight tasks. Fast responses (~800ms).

Returns complete model catalog with capabilities, pricing, and restrictions. Heavily cached (max-age=21600).

POST /models/session

Model selection with auto-mode hints. Returns session token with selected model and discounted costs.

GET /agents/sessions

Lists active agent sessions for collaborative coding tasks. Supports pagination and filtering by repository.

GET /agents

Returns available agents. Currently returns empty array in standard configuration.

🛠️ Building Your Own: Key Takeaways

If you're building an AI-powered development tool, here's what you should know:

1. Multi-Model Flexibility is Essential

Copilot doesn't lock you into one model. The /models endpoint provides a dynamic marketplace. Users can switch models mid-conversation. Design your architecture to support multiple providers from day one.

2. Streaming is Non-Negotiable

All major endpoints support SSE streaming. Users expect to see responses appear word-by-word, not after 60+ seconds of waiting. Implement stream: true and handle SSE properly.

3. Context is King (But Expensive)

Copilot sends massive payloads (400KB+) but still truncates some content. Implement intelligent context selection:

  • Prioritize recently edited files
  • Include file structure for navigation
  • Compress or summarize long conversations
  • Use semantic search to find relevant code

4. Tool Support Enables Real Work

The difference between a chatbot and an agent is tool use. Copilot can:

  • Search your entire codebase
  • Read and edit files
  • Run terminal commands
  • Remember context across sessions

Design your tool schemas carefully and implement proper error handling.

5. Cost Management from Day One

GitHub tracks usage with three quota types:

  • Chat interactions (free tier)
  • Completions (code suggestions)
  • Premium interactions (advanced models)

Implement quota tracking, show remaining usage to users, and offer degradation (fall back to cheaper models when quota is low).

6. Security & Compliance

Every request includes:

  • Content safety filtering
  • IP address logging
  • Device fingerprinting
  • ASN (network provider) tracking
  • A/B test assignment context

Plan for compliance (GDPR, SOC2) from the start.

⚡ Performance Optimization Strategies

What GitHub Does Right

  1. Aggressive Caching: Model catalog cached for 6 hours
  2. Connection Reuse: All requests use Connection: keep-alive
  3. Compression: Accept-Encoding: gzip, deflate, br, zstd
  4. Parallel Requests: Model checks and session setup happen simultaneously
  5. Content Filtering Pipeline: Both prompt and response filtered in real-time

Bottlenecks Observed

  • Initial Model Selection: Adds ~2 seconds to first message
  • Large Context Serialization: 400KB+ JSON payloads
  • Tool Call Overhead: Each tool invocation adds round-trip latency
  • Thinking Token Budget: Extended reasoning can double response time
